# Un Millimetro Sotto

Reel 2D animati (Instagram + TikTok `@unmillimetrosotto`): la scienza un millimetro sotto le cose di tutti i giorni.

- `reelkit/` – libreria di scene + pipeline `storyboard JSON → voce ElevenLabs → video 1080×1920`
- `reelkit/storyboards/` – un file per reel (testo, scene, fonti, verifiche)
- `reelkit/themes/` – palette (la serie cucina usa `cucina_notte`)
- `media/` – video pronti da pubblicare
- `registro.json` – temi fatti e stato di ogni reel

La chiave ElevenLabs NON sta in questo archivio.
